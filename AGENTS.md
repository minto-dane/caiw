# caiw — Compressor for AI Weights

Lossless (byte-exact) archiver for safetensors model weights. Single dependency-free C file (pthread only).

## Build

```
gcc -O3 -march=native -Wall -Wextra -pthread -o caiw caiw.c -lm
```

## Usage

```
./caiw c out.caiw [-j N] [--ref base.st ...] in1.st [in2.st ...]
./caiw d out.caiw outdir/ [-j N] [--ref base.st ...]   # same --ref set+order as c
./caiw v out.caiw [-j N] [--ref base.st ...] in1.st [...]
```

- `c` compress, `d` decompress to safetensors, `v` verify against sources — BIDIRECTIONAL: every archive tensor must exist in the source with equal dtype+shape+bytes, every source tensor must appear in the archive (MISS-SRC), no duplicates (DUP), file set and `__metadata__` compared positionally (FILE/META).
- `-j N` threads (`-jN` also accepted; `-j` must be followed by digits). Default = online cores capped at 8, clamp 1..64. `-j 1` = fully sequential. Archives are thread-count independent on the decode side: an archive written at any -j decodes to identical bytes at any -j. Encoded bytes themselves may differ across -j (batch boundaries change which model state each tensor sees).
- `--ref` repeatable; best external reference is chosen per tensor by sampled escape rate and its file index is stored in the archive. Decode prefers the recorded index, then falls back to a name+len+dtype scan of all `--ref` files (`ref_resolve`) — a wrong-but-compatible ref decodes to wrong bytes and dies on the CRC check; a missing compatible tensor dies loudly. The archive records a file *index*, not ref identity — pair `--ref` files with external checksums if provenance matters.

## Format

`CAI5` magic (decoder/verifier also accept `CAI3`/`CAI4`/`CAI6`; new archives are stamped `CAI6` iff at least one tensor actually uses M_FIELDT, else they stay CAI5 so older decoders keep reading them). File table: `[u32 basename_len][basename][u32 meta_len][meta]` — `meta` is the source `__metadata__` object stored verbatim (absent in CAI3/4). Per-tensor record: name (raw bytes), dtype, shape (nd<=64), file idx, method byte, len, ref (intra idx for REF/DELTA, ref-file idx for DELTAX), payload len, CRC32, payload. Methods (low 6 bits): RAW PACK REF FIELD FIELDPOS FIELDROW DELTA U8 F32 DELTAX PRW FIELDT. M_FIELDT in an archive with version <6 is rejected (old encoders could never emit it). PRW carries no ref field; payload is `[u32 len][FIELD(row0)]` then per row `[u32 len][DELTA16 stream]` — each row's residual is coded against the previous row, and the per-row framing guarantees the referent row is fully decoded (incl. escapes) before use. FIELDT payload is `[u32 tlen][table][emit_blk stream]` where table = `[u16 fs0][u16 fs1]` (both >=1, sum TOT), `[u16 E0[ew]][u16 E1[ew]]` (dense, each row sums to TOT), `[u16 nmr]` then `nmr` × `[u16 ctx][u16 f[mw]]` with ctxs strictly increasing and each row dense + sum TOT; a (sign,exp) ctx with no transmitted row decodes mantissas uniformly at f=TOT/mw (power of two — no table read).

`safetensors` input parsing is real JSON, not substring matching: `jstr` decodes all escapes incl. `\uXXXX` (surrogate pairs -> UTF-8), `jspan` skips balanced objects/arrays string-aware, `jget` walks key:value pairs with proper value skipping. Tensor names are stored UNescaped in the archive and re-escaped (`jesc`) when `d` regenerates headers — escaped names like `a\"b` round-trip through the official loader. Enforced at load AND at archive-decode: `product(shape) * dtype_size == len` (rejects >64 dims, shape/len mismatch, negative dims); duplicate tensor names within a file are rejected; names/dtype strings must be strict UTF-8 (`utf8_ok` — no lone surrogates, overlongs, or >U+10FFFF) so regenerated headers are always valid JSON; `__metadata__` is validated by a real recursive-descent JSON grammar (`jval`/`jstrv`/`jnum`, depth-capped at 128) — not just brace balance — so malformed meta can never be replayed into output.

Method byte flags (CAI4+):
- `0x80` MF_BAT: tensor belongs to a parallel batch — decoded against the batch-start entropy snapshot.
- `0x40` MF_BH: first member (head) of a batch. Head = 0x80|0x40, members = 0x80, solo = no flags.
- Batches: encoder groups consecutive tensors whose every intra-archive ref (dup target + all DELTA candidates) predates the batch (`joinable()`); workers encode against a snapshot of committed hist state, then hist deltas merge (`worker += worker - snapshot`, counts are additive/order-free). Decoder rebuilds identical snapshots at MF_BH boundaries. Orphan member / ref into open batch = hard error.

## Test / regression

- `./test.sh` — self-contained regression to run **after code changes** (not needed for docs-only edits): generates fixtures via `gen_fixtures.py` (pure Python, no numpy), exercises `-j1`/`-j4`, checks `0 bad`, PRW selection + round-trip on `rows.st`, FIELDT selection + CAI6 magic + cross-thread byte-identity + corrupted-table rejection on `f16t.st`, metadata round-trip, incomplete-source `v` failure, and `tests/corpus/` crash inputs (captured from past mutation audits) must die cleanly.
- Synthetic fixtures in `out/` (generated): `edgeA/edgeB.st` (all dtypes, 0-dim, empty, dups, delta pairs), `ch*.st` (3-checkpoint f16 chain — DELTA must win), `f32A/B.st` (f32 pair), `exp.st` (10-tensor MoE-like), `pack1.st` (k=1 PACK — ib=0 edge), `escname.st` (quote/backslash/unicode names), `ndim9.st` (rank-9), `meta.st` (`__metadata__`), `split.st` (64 small bf16 tensors — teach/cold-start), `rows.st` (smooth-row F16 matrix — PRW must win + round-trip), `f16t.st` (drifting-exponent BF16 — FIELDT must win, CAI6), `dx*.st` (DELTAX), `olmoA/B.st` (956MB real F32 pair, generated locally only).
- Models in `models/` (HF safetensors, local only). Verified: pythia pair (332t), MoE shard (1063t), qwen3-4b (398t), OLMo F32 pair (173t, DELTAX 170).

## Notes for contributors

- All methods compete by *actual encoded size*; the winner is always chosen by real bytes. Sampled estimates may only PRUNE candidates before trials (pos_gain>0.06, prw_gain bits/elem<9, sampled DELTAX escape rate) — never decide the winner. Document any addition.
- Prefix pre-filter (in `compete`, tensors ≥512K elems): every candidate is first encoded on a prefix of `min(ne/8, PREF_EL)` elements (FIELDROW caps the row count, keeping row length); candidates projected >1/6 + 256KB behind the best prefix are dropped without a full encode. This is still pruning, not selection — every survivor (including all prefix failures) gets a full-size trial, so the winner remains chosen by real bytes. Dropped candidates that would have won at full size are the only source of output change (rare; prefix rates track full rates within a few %). Prefix trials use the same TJob wave machinery as full trials — parallel on the solo path (psp=min(ntry,nc), TRYBUD-bounded), sequential inside batch workers (ntry=1). Do NOT skip pos_gain/prw_gain when prefix engages: a FIELDPOS prefix still pays the full K-context normalization per block (K depends on P, not the prefix length), so the sampled gains remain the cheaper pre-prune for large-K tensors.
- DELTA16 residual coding is conditioned on `ref>>9` (128 ctxs); DELTA32 XOR planes conditioned on `ref>>23` (256 ctxs). Context tables normalize only contexts used in the block (used-mask), decode side reconstructs the same set.
- Parallel candidate trials: each candidate encodes once against a clone of the same model state; smallest real size wins; only winner's hist delta commits — output identical to sequential competition. Trial buffers fold into a rolling best (`nsp` concurrent scratch + 1 retained), so TRYBUD is a real concurrent bound.
- Cold start: RAW/PACK winners emit no channel stream, so `teach()` counts their elements into the natural channel (CBF/CFP/C32/C8) on BOTH sides — encode (post-commit) and decode (post-payload). Any future streamless method must join `teach()` or document why not.
- Model histograms are `uint64_t` (no periodic rescale — rescale would desync the batch delta-merge). In-block cum/sym frequency tables stay u32/u16 (bounded by TOT=2^15).
- mmap everywhere: keep offsets page-aligned; drop consumed pages with `drop_pages`.
- DELTA16 escape values are coded through the shared FIELD channel (measured better than a dedicated channel).
- PRW (prev-row delta): F16/BF16 tensors with nd>=2, last-dim >=64, rows<=65536 may add a candidate that codes row i as kmap16 residual vs row i-1. Rows are SEPARATE DELTA16 streams (`dlt_enc_ws`/`dlt_dec_ws` share a `DltWs` scratch so per-row calls don't mmap-churn). A single whole-tensor stream is NOT safe: `dlt_dec`'s per-block used-mask reads the ref row up-front, which with a self-referential lag < BLK would read not-yet-decoded positions, and deferred escapes would still be 0 placeholders when read as refs. `prw_gain` prunes hopeless tensors by sampled residual bit-estimate before the real encode.
- Cold start: RAW/PACK winners carry no rANS streams, so without help a run of small tensors would keep the float channels at their all-ones init forever. `teach()` counts every RAW/PACK winner's elements into its natural channel (CBF/CFP/C32/C8) on BOTH sides — the decode replay is identical, so the model warms up even when RAW keeps winning. (Split-tensor fixt: 64x256x256 bf16 went from ~100% RAW to ratio 0.660, beating the single-tensor 0.666.)
- Candidate trials keep only the rolling best (buffer + hist clones), so peak try memory is ~(nsp+1) x ebound — `TRYBUD` now actually bounds concurrent scratch. Note ebound is VIRTUAL reservation; resident use tracks real encoded size.
- Histogram cells are `uint64_t` — no rescale needed; `hmerge` deltas stay exact for any archive size. `cum` prefix tables stay u32 (sums <= TOT=2^15).
- Encoder hist updates are FUSED into the backward rANS encode loop in every stream encoder (f16/f32/u8/pos/dlt16/dlt32) — the old separate forward re-read pass is gone; increments commute and the encoder only ever reads the normalized ft/cum snapshots, never h mid-block. pos_enc/pos_gain compute po/ctx incrementally (one seed division per block/call, then add/subtract steps — K<=P so ctx moves <=1 per po step; identical values, no per-element division). `pos_gain2` evaluates BOTH position gates (column + rowwise) in one sample pass with u32 histograms and a shared marginal — same counts, same gate decisions, half the data reads. pos_enc norms only the block's USED ctx range(s): po values in a block are contiguous (rowwise monotone, column run or wraparound pair) and ctx=po*K/P is monotone, so norm_ctx/cum run on [po_lo*K/P .. po_hi*K/P] only — per-ctx norms are independent so the emitted bitstream is unchanged and the decoder (full-K norm) needs no format hint. po clamps to P-1 (P∤n is reachable only via FIELDROW prefix rescaling — real tensors always have P|n); the ctx range also clamps to K-1 defensively and the first ceil(sew/mw) mantissa rows are normed unconditionally since the pos-band write h[ctx*sew+SE] would alias them if ctx ever reached K.
- emit_rec's record CRC is precomputed inside ejob_run for batch members (overlaps sibling encodes; emit uses t->crc for bat>0, computes inline for solo). The archive FILE* gets an 8MB stdio buffer so large payload fwrites skip the 4KB bounce.
- Two more parallelism levels, both byte-identical: (a) batch workers get a candidate-trial budget `ntry = g_threads/nm` (+remainder) so a batch smaller than the thread count still uses all cores for trials — candidate results are deterministic so the archive is unchanged; (b) a trial wave running `sp` jobs splits the budget as `nthr = ntry/sp` and f16_enc honors it with block-parallel encoding — each emitted block is a self-contained bitstream (x=LOWER + len in the header), so once a block's ft snapshot is fixed its encode is independent. Waves run [A1 parallel per-block u32 count] → [A2 serial norm+merge (the model dependency chain)] → [parallel rANS encode] → [serial in-order emit_blk]. ALL stream encoders take nthr>1 now — FIELD/FIELDT/F32/U8/FIELDPOS/FIELDROW/DELTA16/DELTA32 (DELTA16's element pass builds cB/sB/used/escapes in parallel — cur+ref only, no model state — then serial norm+merge, parallel encode; DELTA32 is per-plane wave-parallel since h is shared across planes; pos_enc's per-block build derives the po/ctx range + mantissa mask then counts with a forward incremental po walk; U8 is a trivial single-table version; PRW per-row calls stay serial). pos_enc correctness detail: rowwise po=gi/D can exceed P-1 when P∤n (prefix trials rescale P so it no longer divides the prefix length) — po is CLAMPED to P-1 on both serial and parallel paths (the previous unclamped indexing was a latent OOB reachable via FIELDROW prefix), and the first ceil(sew/mw) mantissa rows are normed unconditionally since a clamped/edge ctx aliases that table area. pos_gain2's rowwise por clamps identically. f16_enc (serial + A2/encode phases of the parallel path), f32_enc, and pos_enc's mantissa channel also norm only USED ctxs per block: a used-se mask (one cheap forward pass over the block, or fused into the parallel count phase) skips unused sign×exp mantissa rows — real tensors touch ~30-60 of 512, cutting per-block norm ~10x; unused rows' stale ft cells are never read by either side (decoder norms all ctxs from its own h — identical values for used ctxs).
- FIELDT (M_FIELDT=11, stamps the archive CAI6) is FIELD with the model made explicit: instead of re-normalizing per block from the evolving channel state (which chains decode strictly serially), it counts the whole tensor once, normalizes ONE frozen table over `h_start + own counts`, serializes it into the payload, and encodes every block against it — blocks are then independent bitstreams and `f16t_dec` decodes them in parallel under nthr (header scan stays sequential). The channel's post-tensor state is identical to FIELD's on both sides because counts are additive: the encoder merges its own counts before normalizing, and decode workers defer their per-element counts into private u64 histograms merged after join (verified: FIELD-enc/FIELDT-enc/FIELDT-dec histogram parity is exact). Table v2: S/E rows are dense and always sent; a mantissa row is sent only where its measured adaptive cost beats uniform coding by more than the row's serialization bytes (Q20 flog2 arithmetic — integer-only for archive determinism), and absent rows decode at f=TOT/mw. Encoder-side FIELDT is itself block-parallel (count wave → serial norm → encode wave). Selection: FIELDT is retained as a near-best candidate and preferred within ~0.8%+4KB of the byte winner (bounded ratio cost for parallel decode); on pythia-class real weights it beats FIELD outright (~-1.3%). The payload gains a trust-boundary table parser (`f16t_dec` — every row bounds/freq/sum/order-checked, exact tlen consumption enforced).
- Batch bookkeeping is no longer serial-heavy: there is no upfront hsnap — workers clone gch directly (it is never written while a batch is in flight) and hmerge materializes snap[c] lazily at a channel's FIRST merge (gch[c] is still batch-start then), so only channels a member actually committed are copied. Batch emit (emit_rec + fwrite + drop_pages) is deferred one batch so it overlaps the NEXT batch's encode — file order is unchanged since emits still happen in record order. DECODE side gotcha: a batch wider than the decode -j is processed in chunks; later chunks must NOT read gch (earlier chunks' merges have landed) — each chunk builds view[c] = snap[c] ? snap[c] : gch[c], which works because an unmerged channel's gch[c] is untouched. Verified by `v` at -j1/-j2/-j4 against archives encoded at -j8.
- CRC32: callers go through `crc32b`, which dispatches to a slicing-by-8 path (`crc32_slice`, tables derived mechanically from `crc_tab`, ~5x throughput on LE hosts) after a one-time differential self-test against the WP-proved scalar `crc32_of`; any mismatch (e.g. big-endian host, where the memcpy word load order differs) permanently falls back to scalar. `crc32_of`/`crc_setup` stay untouched so their WP proofs still stand; `crc32_slice`/`crc_setup8`/`crc32b` are unverified glue covered by the self-test + regression.
- Batching costs ~0.8% ratio on pythia pair (cold-start model state per batch) — inherent trade for parallelism. Tensors with promising in-batch refs are kept solo (`joinable`) so no DELTA/REF win is ever dropped.
- CAI5 vs CAI4: new archives preserve `__metadata__`; CAI3/CAI4 archives still decode but old `v` reports META when the source has metadata — that archive genuinely lost it.
- Host has ~8GB RAM — avoid loading multi-GB tensors into anonymous memory; numpy probes must use memmap + bounded samples.

## Hardening / verification status (2026-09)

Malformed-input contract: every archive/loader failure exits(1) with a `die()` message — never crashes, never OOB, never silent corruption of decoded bytes (CRC32 verified on every tensor; `c`/`d` outputs are all-or-nothing via tmp+rename with `atexit` cleanup). Scope notes: CRC32 is corruption *detection*, not authentication — an adversary can forge an archive that passes it (hash/sign the archive externally if provenance matters). "All-or-nothing" covers die()-driven failures; SIGKILL/power loss between renames can leave a partially-renamed set, and outputs are not fsync'd. mmap of an input truncated concurrently by another process can still SIGBUS — an OS-level race no userspace tool can fully close. Portability edges: member-name uniqueness is byte-exact — case-insensitive or Unicode-normalizing filesystems (APFS/NTFS) can collide two distinct members on disk; `d` keeps all `nf` outputs open at once, so an archive with more files than `RLIMIT_NOFILE` dies loudly (raise ulimit); archive framing fields are all explicitly little-endian, but element payloads are interpreted in host order — archives are portable across little-endian hosts only (x86/ARM-LE); on a big-endian host a foreign archive would fail loudly at CRC, never corrupt silently.

Decoder trust boundary checks (all present — do not remove):
- Record walk: `BND` before every field; `nd<=64`, `file<nf`, `ref<i`, `method<=M_FIELDT` (+ `M_FIELDT` requires cver>=6), `plen` within buffer; `prod(shape)*dbits/8==len` (spec floor-div; sub-byte dtypes OK) enforced on records (decode AND verify; unknown dtypes are opaque 8-bit); `MF_BAT` orphan-member rejection; REF/DELTA member may not ref into its own batch (`ref >= bstart` → die) — parallel decode would otherwise read a not-yet-decoded (NULL) referent.
- `dec_tensor`: method/dtype coherence is canonical — FIELD/FIELDPOS/FIELDROW/PRW/FIELDT require is_flt16, F32 requires is_f32, DELTA/DELTAX require flt16|f32, U8 rejects is_flt16 (encoder emits U8 for every other dtype incl. integers/F64), PACK needs bsz<=2, RAW needs plen==len, REF needs plen==0, and in the record walk DELTA's referent must share the record's dtype and `__metadata__` is a reserved tensor name (prevents a duplicate-key header on regenerated output). Records the encoder can never emit are rejected outright (mirrors the encoder gates; PRW also needs nd>=2 + cols∈[64,2^28] + rows∈[2,65536] — the cols cap keeps a row's stream under the u32 length field).
- Resident decode set is bounded: `g_dlive` charges each in-flight tensor `len + dec_aux(method)` (DELTA16: escape values ≈len + bitmap ≈len/16 + possible misaligned-ref copy ≈len + ~3.3MB decode workspace — the encoder-only scr/cB/sB fields are skipped by `dltws_init_dec`; DELTA32 planes ≈len, DELTAX aligned ref copy ≈len, PRW per-row escape workspace ≈len/2 (escbuf sized cols*2 upfront), pos-ctx tables ≈14MB, FIELDT ≈ft/cum ~0.4MB + nthr×~528KB deferred-count histograms + ~24B/block header arrays, 4MB fixed-workspace floor) plus a one-time charge for the record table + dup-name set (`NT×(sizeof(Tensor)+512) + dcap×16` — ≈22x archive-size amplification that would otherwise slip past the bound), and dies once the total exceeds MemAvailable (parsed from `/proc/meminfo`; NOT `_SC_AVPHYS_PAGES` — that returns freeram, which excludes reclaimable cache and would spuriously kill legit decodes; on non-Linux hosts lacking /proc/meminfo the AVPHYS fallback IS that too-strict metric). A decompression-bomb archive dies deterministically instead of being SIGKILLed mid-write by the OOM killer. Non-referenced RAW tensors bypass `dec_tensor` entirely (zero-copy: payload IS the tensor bytes — crc + teach + write/compare direct from the archive buffer), which also keeps them out of `g_dlive`. Remaining uncounted-but-bounded: per-batch hist snapshot (~44MB), winner payload buffers held until batch emit (≤BCAP), encode-side TRYBUD scope (virtual reservations, not resident).
- `d` writes `name.caiwtmp` then renames after all files close cleanly; rename targets are tracked in `g_outp` too, so a late failure unlinks already-renamed files — output is all-or-nothing *on die()-driven failure* (SIGKILL/power loss mid-rename can still leave a partial set; no fsync). `c` likewise writes `<out>.caiwtmp` and renames at the end — a failed encode leaves no half-archive. Temp opens use O_NOFOLLOW|O_NONBLOCK (planted symlinks/FIFOs in a shared outdir can't redirect or hang the write). Temp-name collision is rejected up front: a file-table entry equal to another member's `<name>.caiwtmp` would make the rename clobber the wrong output (crafted archives could pair `a` with `a.caiwtmp`). Path-identity checks (text + stat dev/ino + realpath-dir) run BEFORE the tmp open and cover inputs, --ref files, the archive itself, and both names (final + .caiwtmp) — they are best-effort, not a hard TOCTOU-proof boundary.
- `c` rejects input basenames that `d` cannot write (`\`, `.`, `..`, >3000B) — an unwritable archive is never produced. Self-destruction guards (`same_out_path`: byte-compare, then `stat` dev+ino, then realpath-canonicalized dir+basename): `c` refuses input/`--ref` paths equal to the output path — including symlink/hardlink/`dir/../x` aliases; `d` refuses a member whose output path is the archive itself (a symlinked outdir counts); `c` also refuses basename pairs that collide under `<name>.caiwtmp` (e.g. `a` + `a.caiwtmp`), so every emitted archive stays decodable. `-j`/​`--ref` memmoves keep argv's trailing NULL. `sizeof(size_t) >= 8` is a compile-time requirement — all length arithmetic is u64.
- `die()` is reentrant-guarded (a `dying` flag sends concurrent worker dies to `_exit`) — two threads racing into `exit()` can't re-run atexit handlers (exit is not thread-safe).
- `BND` is negative-subtraction safe (`q > bend` checked before the difference is taken). `data_offsets` accumulation in `d` is bounded by INT64_MAX (off_t is signed; a u64 wrap would make fseeko UB on crafted lens). The dup-name table caps at 2^30 entries — the earlier 2^32 bound could make `dcap` wrap to 0 and index an empty table.
- `c` preprocessing (dup/dref/fref resolution) uses newest-first hash chains keyed by (len,fnv), name, and normalized family name — identical "latest match" semantics to the old O(NT²) scan, near-linear in practice. Byte-identical output verified on the pythia pair.
- `prw_dec`: per-row `[u32 len]` framing, `l1`/`lr` bounds-checked against the payload limit, and `in == lim` exact-consumption enforced at the end.
- Payload decoders take `lim` (payload end) and ALL enforce exact consumption — `rp == lim`/`in == lim` at exit, so trailing garbage inside a record is rejected rather than ignored: `read_blk` validates 12-byte block header + block len; `pack_dec` validates k∈[1,256], dict bytes, `idx<k`, exact bit-position bounds (`in + ((bit+ib-1)>>3) < lim` — a looser check permits a 1-byte over-read at payload end) AND `lim - in == ceil(ne*ib/8)` at exit. `dlt_dec_ws` checks the stored escape count against decoded escapes and requires `rp == lim` when the count is 0 (the nonzero case is exact via `f16_dec`'s own tail check).
- `st_load`: real JSON string/object handling (escapes, nested braces, surrogate pairs); header len ≤ 2^30; name ≤ 65535B, dtype ≤ 64B, nd ≤ 64; `b>=a`, `off+len` non-wrapping, `prod(shape)*dbits(dtype)==len`, dup names rejected via open-hash (not O(n²)), `__metadata__` span is ck_meta-validated at load (object/array/string or strict JSON literal — crafted scalars like `12x` are rejected), and `dsz > filesize - 8 - hl` via fstat — subtraction form, because `8+hl+dsz` itself wraps on near-UINT64_MAX data_offsets (AFL-found real SIGBUS).
- File table (d AND v): `nf`/`nfa` ≤ 65535 (u16 idx), per-name len bound + embedded-NUL rejection + `..`/`.`/`/`/`\` rejection (d side), dup filenames rejected via open-hash; CAI5 `__metadata__` replay is ck_meta-gated — malformed meta can never reach regenerated JSON.
- Thread dispatch: every `pthread_create` site records success in `job.spawned`; joins are gated on it — inline fallback leaves `th[]` entries unjoined (joining an uncreated pthread_t is UB; glibc's ESRCH was luck). Worker `gh`/`gsnp` are save/restored around inline AND threaded runs so the main thread's channel pointers never dangle into a freed snapshot.
- `-j` accepts digits only (`-j 12x` dies); a non-digit `-j*` token falls through to input parsing and dies on open.
- `pos_enc`/`pos_dec`/`pos_gain`: `P<=0` rejected AND `D=n/P` clamped to >=1 — a degenerate shape with P>n gave D=0 → `gi/D` SIGFPE (AFL-found).
- Encode output buffer: `ebound(len)=4*len+len/1024+64MB` is a proven upper bound — ≤2 emitted bytes per enc() call; FIELD does 3 calls/elem (3*len); DELTA16 escapes recode through f16_enc (len+3*len=4*len — the max); DELTA32/F32 ≤2.5*len. Trial encodes write the full stream regardless of winner, so under-sizing overflows on adversarial inputs even when the method loses.
- Alignment: `alview()` supplies aligned copies for odd-offset safetensors data; DELTAX ref tensor is alview'd on the decode side too; sampling paths and `teach()` use memcpy loads (teach can see the unaligned archive payload on the zero-copy RAW path).
- `norm_ctx` uses a u128 multiply only when `tot >= 2^49` (u64 `h[i]*bud` can overflow past that; the wide path is a per-call branch so the hot loop stays u64).
- rANS state invariant: x ∈ [LOWER, 256·LOWER) at every enc/dec boundary (blocks init x=LOWER; enc preserves it — verified exhaustively). Encoder scratch is SCRSZ=BLK*16+64 (worst case 3 emitted bytes/enc call, ≤5 calls/elem).
- `tests/corpus/` keeps AFL-discovered crash inputs as a permanent regression corpus; `test.sh` runs the full suite (round-trips -j1/-j4 + DELTAX + crash corpus must-die-clean).

Verification record: the codec has been validated by layered tooling — ASan/UBSan/MSan/TSan, AFL++ audits (all findings fixed; crash corpus in `tests/corpus/`), exhaustive boundary sweeps, static analyzers (gcc -fanalyzer, scan-build, clang --analyze, cppcheck, valgrind), and formal layers under `verify/` (TLA+/Alloy/CBMC/ESBMC, Frama-C EVA+WP, five Rocq proofs covering the domains BMC could not reach). CI reruns the suite on every push. These layers are heavyweight and already green — do NOT re-run them for routine edits; `verify/verify.sh` matters only when the archive format, decoder trust boundary, or entropy primitives themselves change. The full per-layer evidence lives in git history.
